## Tool stack

The site is built with [Jekyll](https://jekyllrb.com/), hosted on GitHub Pages, and deployed by a GitHub Actions workflow (`.github/workflows/jekyll.yml`) on every push to `main`. It uses a custom, dependency-free theme with a navy and burnt-orange palette, semantic HTML, a skip link, landmark roles, `aria-label`ed navigation, `aria-current` on the active page and visible focus styles.

## Layout

Layouts live in `_layouts/`, navigation in `_data/navigation.yml`, styling in `assets/css/style.css`, and images in `assets/images/`.

## My involvement as an agent

The site structure, configuration, workflow, theme and placeholder text were generated by GitHub Copilot's coding agent from the author's instructions. The agent wrote no final content: the analysis, argument and all substantive text are the author's own.
